## 字段与口径

- **日期 / 星期**：站点「直播记录」的场次日期。跨零点的直播站点会拆成两行（如 21:15–00:59 与 00:49–00:57），后一行是前夜的续接。
- **直播标题 / 起止时间 / 标签**：站点 `info`、`record` 字段；2017-07～2019 年上半年不少场次站点只存了歌单，标题/时间/转录/录播均为空，标为「站点未记录」。
- **歌单**：站点记录的各首歌「演唱时间点 + 曲名 + 原唱」；无演唱的场次（读书回、游戏回等）为空。
- **文本转录**：站点 `record.content` 收录的直播文字记录（多数带 `[HH:MM:SS]` 时间戳）；`暂无`、`无` 视为没有转录。
- **录播链接**：优先站点登记值（纯净版 / 含弹幕版）；没有时用 B 站检索按「日期 + 标题」匹配，置信度分「高 / 中 / 疑似」：
  - 高：官方「直播回放」系列或合集分 P，标题含当日日期；
  - 中：粉丝录播号目录命中，标题或发布时间与直播日期自洽；
  - 疑似：仅日期吻合但为片段/合集等弱证据，已单列待核实；
  - 未找到：B 站无对应投稿，列入附录。

## 已知限制

1. 站点对 2017-07～2019 年上半年的部分场次没有存标题和录播，这部分无法从站点补齐。
2. B 站 2017-10-24 之前的场次基本没有存档（官方合集从 2017-10-24 起），早期 20+ 场是「B 站确实无录播」而非漏查。
3. B 站匹配按日期+标题自动打分，个别场次可能存在「同一晚多份录播（21点场/22点场、纯净版/含弹幕版、直播回放/粉丝录播）」的情况，主表取最优一份，`archive.json` 的 `alternates` 保留了备选。
4. 「无站点记录」的场次时长/时间为空，非抓取失败。
5. 转录按站点原样收录，个别篇目正文开头标注的日期与场次日期相差几天（站点录入如此，未做改写）。
6. 未找到录播的 54 场集中在上游：其中 2017-07-18～2017-10-07 经深挖确认 **B 站不存在 hanser 专属录播存档**（官方回放合集始于 2021-10；589P 直播合集始于 2017-10-24；粉丝录播号最早 2017-10-25）；2017-08-08、2017-08-12、2017-08-30、2017-10-03、2018-06-16、2019-03-21、2019-03-24、2019-04-18 这 8 天连「当日他人同场录像」都没有。
7. 另有约 30 个早期日期存在同日 **YUKIri** 的直播录像（二人联动时期），但标题未确认 hanser 出镜，为避免误配**未并入**本档案（线索保留在 `../research/bili_matches_deep.json`）。
