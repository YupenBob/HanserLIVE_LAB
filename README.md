# HanserLIVE_LAB · hanser（憨色）直播记录完整档案

把 [毛怪俱乐部 · 直播记录](https://song.2550505.com/livestreams) 的**全部历史直播记录**整理成结构化档案：每场的**歌单**、**文本转录**、**录播链接**（站点没有的去 B 站按日期匹配补全）。

- 整理时间：2026-10-31
- 数据源：song.2550505.com（站点后端接口 `2550505.com/song`）+ B 站检索
- 覆盖：**1035 场直播**，2017-07-18 ～ 2026-10-26

## 方法

1. **站点抓取**：站点是 Next.js SSR，每个 `/livestreams?date=YYYY-MM-DD` 页面的 `__NEXT_DATA__` 里含该场的 `info`（标题/起止时间）、`record`（转录、标签、录播链接）、`songs`（歌单）；按页面日历的 `days` 字段逐月枚举出全部 1035 个场次日期，再逐日抓取。
2. **B 站补全**：站点无录播链接的 213 场，用 B 站「官方直播回放」系列（mid 11073 / series 407852，554 个）、589P 直播合集（`BV1Gb4y1k7MX`，2017-10-24 起）、粉丝录播号目录（hanser的aisaka、Rayzggz、中打码の゜等）建本地目录，按「标题日期 + 发布时间 + UP 主 + 时长」打分匹配；证据弱的列为「疑似」，找不到的列入附录。
3. **站点有反爬**：请求过快会被 Server Torii 拦截（403/ALTCHA 验证），因此按约 1 请求/秒 低调抓取，脚本内置了验证码求解与退避重试。

## 已知限制

- 2017～2019 上半年部分场次站点只存了歌单，没有标题/起止时间/转录/录播，档案中标注「站点未记录」。
- **2017-07-18 ～ 2017-10-07 期间 B 站不存在 hanser 专属录播存档**（官方回放合集始于 2021-10，589P 合集始于 2017-10-24，粉丝录播号最早 2017-10-25）；其中 2017-08-08、2017-08-12、2017-08-30、2017-10-03、2018-06-16、2019-03-21、2019-03-24、2019-04-18 连当日他人同场录像都没有。
- 约 30 个早期日期存在同日 **YUKIri** 的直播录像（二人联动时期），但无法确认憨色出镜，未并入档案（线索在 `research/`）。
- 转录按站点原样收录，个别篇目正文开头标注日期与场次日期相差几天（站点录入如此）。
